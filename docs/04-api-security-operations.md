# 接口、安全与运行要求

> 状态：历史候选设计（保留原方案与评审语境）。本文不作为当前功能规格或验收要求；当前实现见 [资源入库闭环](12-resource-ingestion.md)，开发与验证见 [开发工作流](development-workflow.md)。下文的“当前”“本轮”均指历史编写阶段。

## 2026-09-16 Demo 快照（历史）

[OpenAPI](../contracts/openapi.yaml)用标签及 `x-implementation` 区分已实现接口与后续候选接口。服务只开放登录、用户信息与菜单、同权账号管理、日志、场景和场景审计。候选接口不会因为出现在文档里而获得访问权限。

登录沿用若依 `/login`，返回 Token；请求使用 `Authorization: Bearer ...`，Redis 保存登录状态。旧 `/api/v1/auth/*` Session/CSRF 候选接口已移除。账号禁用或密码变化通过数据库凭证版本使旧 Token 失效，不开放公开注册。

所有日常管理员权限相同。新增账号固定角色，禁止账号物理删除、角色分配和停用最后一个有效管理员。引导账号在创建第一个日常账号后自动停用。

AR 接口使用 UUID、camelCase 字段和 UTC 时间。创建返回 201，字段错误 400，未登录 401，禁止访问 403，不存在 404，并发版本冲突 409。错误包含 `code`、`message`、`traceId`。框架接口继续使用若依 `code/msg`，部分业务错误使用 HTTP 200，前端统一处理两类响应。

场景编辑与启停提交 `expectedVersion`，冲突后刷新再操作，不自动覆盖。场景变更与业务审计同事务提交，审计记录操作人、动作及前后内容，操作人从登录上下文取得。

运行与测试只面向本机隔离环境，入口、秘密文件与复验命令见 [Demo 启动与维护](08-demo-runbook.md)。应用只加载专用 Flyway 目录。

## 后续资源与发布阶段

以下能力尚未实现，须在成品格式确认后细化：

- 对象存储保存文件，数据库保存元数据，下载使用短期签名，不把永久密钥交给前端。
- 未发布内容的管理员预览（匿名客户端读取当前发布版本已实现，见 [资源入库闭环](12-resource-ingestion.md)）。
- 文件粒度、入口与依赖寻址方式通过真实客户端样例确认，不提前实现包内资源解析。
- 白天、夜晚分别发布与回滚，冻结版本不可修改，发布切换与审计同事务完成。
- V0.1 不自动物理删除成品；清理临时文件前生成清单并确认范围。
