## 接入时必须保留的事实

1. 本地服务 `local-viewer/serve.py` 从 `data/bundled-scenes.json` 提供场景配置。实际样本主要通过档位路径列表与 `timeOption` 组织播放；`timeOption` 每对是起点和时长。报告中的 version 1 timeline 可以作为后续设计参考，但本次全目录扫描未找到独立 `.4dm.json` 成品。
2. `local-viewer/public/viewer/manifest.json` 是网页安装配置，不是模型播放清单；平台现有 `download-manifest` 是下载清单，也不能直接等同于播放清单。
3. 样包应按配置引用收集。比如 rocket 的封面在 `4dgs/demo/rocket.jpg`，corgi 的封面和预览在 `4dgs/demo/new/`，只复制同名场景文件夹会漏资源。
4. 档位可能引用相同文件，不能按档位重复计费或重复复制。`new_jazz` 高清有 7 段，时间配置只有 6 对；两个单文件场景没有 `timeOption`。不能把原播放器的隐式补齐行为直接冻结成新平台规则。
5. 解码后的点中心时间可能超出所属播放片段。不得简单以中心时间必须落在片段内作为入库校验规则；需要考虑时间生命周期与跨段可见性。
6. 现有平台适合复用场景—草稿—文件集合、摘要校验与发布指针。文件统一落成内部 `.bin`，资源引用需要映射到文件标识和授权读取接口，不宜依赖物理存储目录等于样本 URL。
7. 当前单文件下载调用 `DraftService.completeFiles()`，继而对集合全部文件执行 `LocalArtifactStorage.verify()`，实际重新读取并计算 SHA-256。作为连续播放读取入口时存在重复全量读盘成本；本次仅源码确认，未做性能基准，也未修改现有管理员下载语义。
8. 容量不能照搬开发默认值：cat 高清模型共 1,174,691,338 字节；双节棍高清单文件 445,008,303 字节。它们分别超过文档所述默认集合 500 MiB、local_demo 单文件 256 MiB；正式配置需按选定样包验证，当前运行配置未查询。

- Python 只读布局检查：读取所有 256 个模型 header，按属性类型字节数计算总长，核对 `ceil(points / 256)` 和参考解码器的精确属性列表，全部通过。
