# 当前 4DGS 场景资源平台架构

更新：2026-11-06，描述本地源码的管理员单场景单模型切换，不代表日常环境已升级。具体接口与验证分别见[资源入库闭环](12-resource-ingestion.md)、[客户端接口](21-client-api.md)及[验证记录](06-validation.md)。

## 业务边界

平台接收线下采集和训练产生的 4DGS 目录或多个文件。一个场景直接关联一套固定模型文件，管理员可编辑名称与说明、启停或删除；模型文件不替换，换模型新建场景。不存在业务版本、发布指针、历史版本回滚或单独发布操作。

管理员上传的非空文件清单全部校验完成后，启用场景自动对客户端可见。停用是独立决定，不被上传完成或重启恢复覆盖。客户端只读目录、清单和文件，服务端不解释画质、分段、坐标或模型内部结构，JSON/ZIP 均原样存取。

用户已确认有播放器，客户端解压与解码已跑通；本轮职责是资源分发接口，不修改播放器。既有旧参考播放器的描述依赖及验收只作为[历史证据](20-4dgs-sample-validation.md)，不能与用户已有播放器混同。

## 技术与部署

| 层次 | 当前实现 |
|---|---|
| 后台 | Vue 3、Vite、Element Plus；统一场景详情承载信息与文件 |
| 网关 | Nginx 提供静态页面、代理管理员 `/prod-api/` 与匿名 `/api/v1/client/` |
| 后端 | Java 21、Spring Boot 3.5、RuoYi 3.9.2，单应用多模块 |
| 数据库 | PostgreSQL 17、Flyway、MyBatis-Plus/MyBatis XML |
| 登录 | Spring Security、Bearer Token、Redis 登录状态 |
| 文件 | `ArtifactStorage` 与私有本地持久卷 |
| 恢复 | 同步启动恢复：先完成删除，再核对未完成上传 |

本阶段继续单业务实例，不引入 OSS/CDN、消息队列或独立 Worker；这些是后续[云分发方案](24-4dgs-content-platform-proposal.md)，不是千人容量已达标。文件仍经 Java 输出，单机带宽限制未因业务简化而消失。

日常云端网关位于 `81.71.154.125:18081`，公网 HTTPS 经 `elma-gohan.xyz` 中继到云端。账号迁移、旧本机持久卷保留、服务地址与部署授权边界以[基础设施记录](10-local-infrastructure.md)为准，本页不对日常环境实时健康作判断。数据库、Redis、私有文件目录不公开；本地验证不得复用日常数据。

## 后端分层

保留 Controller → Service → Manager → Mapper，不为层数增加空接口或微服务。

- `ruoyi-admin`：应用启动、Flyway、运行配置与框架管理接口。
- `ruoyi-framework`：认证、显式路由白名单、Token、异常和数据访问配置。
- `ruoyi-system`：管理员账号、菜单、登录与操作日志。
- `ruoyi-ar/module/scene`：场景信息、固定清单、上传下载、删除恢复及业务审计。
- `ruoyi-ar/module/client`：匿名目录与详情，下载调用场景文件业务服务。
- `ruoyi-ar/storage` 与 `support`：存储和 HTTP Range、相对路径、MIME 等共享机制。

版本业务模块与独立发布路径从当前调用链移除。Service 编排业务和短事务，Manager 组合持久化操作，SQL 留在 XML；存储层只处理字节，不决定场景是否可见。源码导航见[业务导读](23-code-review-guide.md)。

## 数据关系与迁移

`ar_scene → ar_scene_file`。场景保存名称、说明、启停、并发修订号、创建请求键及删除信息；文件直接保存所属场景、相对路径、预期与已验证大小/摘要、状态及操作者。删除意图与最小回执独立保存，审计保留。

V001–V017 原样保留，V018 负责升级：旧当前发布模型保持原场景身份和可见性，其他模型分离为停用场景；文件 UUID 和存储键不改，不移动或清除模型文件。原未发布或已删除模型不因迁移而公开。映射结果和未完成删除需要用非空数据库验证。生产升级需先备份、单独授权，源码实施不授权升级日常数据库。

## 上传与可用性

1. 同次请求原子登记名称、说明、请求键和非空固定清单；相同请求重试复用场景，不重复创建。
2. 文件 PUT 取得共享场景读锁和文件在途标记，短事务记 `UPLOADING`。
3. 事务外流式计算大小与 SHA256，存储从 `.part` 经 `.ready` 无覆盖提交为 UUID `.bin`。
4. 短事务确认 `AVAILABLE` 并记审计。最后一个文件完成后，启用场景自然满足匿名访问条件，无网页发布补操作。
5. 同一文件并发请求 409；不同文件可独立传输。已完成文件不覆盖。失败续传按原清单核对，跳过已确认文件。

当前仅按文件重试，尚无分片上传。传输中断或客户端超时不等于服务端失败，先查询状态。已可用正文不在列表、详情或启动时重复计算摘要；下载端仍须校验 SHA256，以发现同长度存储损坏。

## 启停、读取、删除与恢复

- **启停**：修订号检查后更新并审计。停用使新列表/详情/文件请求不可见，管理员仍可管理；已经开始的字节流允许结束。
- **读取**：只有启用、非空全部可用且无删除意图的场景可匿名访问。文件 UUID 和场景关系核验；支持 GET/HEAD、单段 Range、If-Range 和强 ETag，不提供原始存储目录。
- **删除**：提交意图并停止公开，事务外清理全部文件阶段，完成后删除文件行、保存回执与审计。失败显示删除失败，可重试；重复完成删除为 204，未知对象为 404。
- **恢复**：启动先继续删除，再对未完成上传的完整遗留验证并补记。中断上传没有完整字节时保留可重试失败，已完成文件不全量重算。

内部修订号是并发保护字段，仍在 API 中用于编辑/启停/首次删除；页面隐藏它，不将其称为模型版本。当前共享锁限定单进程，多实例扩容需要另行改造，不能仅复制容器。

## 权限与证据边界

当前均为平权管理员。创建首个日常管理员后引导账号退役；账号凭据或状态变化通过数据库凭据版本使旧 Token 失效。删除账号保留历史身份和日志，保护最后一个有效管理员及当前登录账号。

管理场景文件操作要求管理员身份；匿名只开放三个客户端路由的 GET 和文件 HEAD，其余默认拒绝。HTTPS、云端迁移和旧样包播放记录只对应其日期与基线。

本次验证关注固定清单上传、资源分发、Range/续传、启停、删除、重启恢复和迁移；客户端解压/解码按用户确认沿用，本次不重做播放器。手机、千人并发、OSS/CDN、云端 GPU、断电恢复等能力不从当前单测或接口检查推定。
